Paw Cafe Uploader

1. 목적

이 도구는 YouTube 채널 운영자가 본인 소유 채널의 영상 썸네일을 업로드·교체하기 위해 사용하는 개인용 자동화 도구입니다.

2. 이용 범위

운영자 본인만 사용하며, 일반 이용자에게 배포·판매·제공하지 않습니다. 타인의 계정이나 채널에 사용하지 않습니다.

3. 요금

이 도구는 무료이며, 어떠한 요금도 청구하지 않습니다.

4. 책임의 한계

이 도구는 있는 그대로 제공됩니다. Google API 정책 변경, 네트워크 오류 등으로 동작이 중단될 수 있으며, 그로 인해 발생한 결과에 대해 보증하지 않습니다.

5. 금지 사항

  • 타인의 계정 또는 채널에 대한 무단 사용
  • YouTube 서비스 약관 및 Google API 정책에 반하는 사용

6. 약관 변경

약관이 변경되면 이 페이지에 게시하며, 게시 시점부터 적용됩니다.
